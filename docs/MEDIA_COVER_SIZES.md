核查日期：2026-09-18。尺寸是本工具出图画布，不代表平台唯一允许的上传尺寸。平台账号、客户端、展示入口可能产生不同裁切；发布前仍须在目标平台确认。

## 来源

- [小红书比例创作建议（Oimi，第三方）](https://xiaohongshu.oimi.ai/zh/blog/xiaohongshu-image-ratio)：支持 3:4 / 1:1 的常用推荐，不视为官方标准。
- [公众号头图、次条与正文配图（FrameLab，第三方）](https://framelab.cn/guides/wechat-article-image-size)：横版与方形的区分；正文 16:9 是本工具选择。
- [B 站封面多展示位实测（社区作者）](https://www.bilibili.com/read/cv11029957/)：4:3、16:9 等不同展示位的差异；不是平台官方保证。
- [YouTube 缩略图帮助（官方）](https://support.google.com/youtube/answer/72431?hl=en)：横版 16:9、Shorts 9:16 与当前分辨率、文件大小建议。
- [YouTube 视频比例说明（官方）](https://support.google.com/youtube/answer/6375112)：9:16 属于竖屏视频画面比例，不据此推断其他平台列表封面规则。

## 编辑行为

“统一编辑所有版本”同步文字、模板及拖拽位置，保留各自比例；会覆盖此前单独调整的对应内容。“仅编辑当前版本”保留其他版本。缩略图可切换目标，大预览按实际输出尺寸缩放显示；比例重置回当前媒体推荐值。下载 PNG 使用当前版本像素尺寸，插入封面仍沿用原有文章封面插入流程。

版本目前保留在封面面板的内存中，尚未纳入正文的自动保存历史。PNG 外部字体使用浏览器可用字体；外部图片需可读取。没有自动上传、裁切平台审核或发布功能。
